Install
=======

The easiest way to install is:

.. code-block:: bash

   pip install pensive

This pulls in ``dit`` (and thus the information-theoretic measures) as a core
dependency. Optional extras add visualization, Bayesian backends, and the
development toolchain:

.. code-block:: bash

   pip install "pensive[viz]"    # Graphviz diagrams
   pip install "pensive[bayes]"  # PyMC/ArviZ backends for Bayesian inference
   pip install "pensive[dev]"    # tests, linting, docs, and all extras

For development, we recommend `uv <https://docs.astral.sh/uv/>`_:

.. code-block:: bash

   git clone https://github.com/dit/pensive.git
   cd pensive
   uv sync --extra dev

This installs ``pensive`` in editable mode with all development dependencies.

**Testing**

Run the test suite::

   uv run pytest

Linting and type checking::

   uv run ruff check .
   uv run ruff format --check .
   uv run ty check

**Building documentation**

::

   uv sync --extra docs
   uv run sphinx-build -W --keep-going -b html docs docs/_build/html
