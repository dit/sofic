**************************************
Correlations and power spectra
**************************************

Pairwise statistics of a process generated by any finite HMM presentation
follow in closed form from its symbol-labeled transition matrices
:math:`T^{(x)}`, :math:`T = \sum_x T^{(x)}`, and stationary state law
:math:`\pi` (Riechers & Crutchfield :cite:`riechers2017spectral1`, §V.A). For a
real observable :math:`f` of the symbols set :math:`\Omega = \sum_x f(x) T^{(x)}`.

Autocorrelation
===============

.. math::

   \gamma(0) = E[f(X_0)^2], \qquad
   \gamma(\tau) = E[f(X_0) f(X_\tau)]
              = \langle \pi | \Omega \, T^{\tau - 1} \, \Omega | \mathbf{1} \rangle
   \quad (\tau \geq 1).

``centered=True`` returns the autocovariance :math:`\gamma(\tau) - E[f(X_0)]^2`.
The default observable is ``float(symbol)``, so the binary alphabet ``"0"``,
``"1"`` maps to 0, 1; pass a mapping or callable for anything else.

Power spectrum
==============

The power spectrum :math:`P(\omega) = \lim_{N\to\infty} \frac{1}{N}
E\,|\sum_{t=0}^{N-1} f(X_t) e^{-i\omega t}|^2 = \sum_{\tau} \gamma(\tau)
e^{-i\omega\tau}` (Wiener–Khinchin) of a finite HMM is a continuous part plus
Dirac deltas. :func:`power_spectrum` returns the continuous part
(:cite:`riechers2017spectral1`, Eq. (5)):

.. math::

   P_c(\omega) = E[f(X_0)^2]
     + 2\,\mathrm{Re}\,\langle \pi | \Omega \, (e^{i\omega} I - T)^{-1} \, \Omega | \mathbf{1} \rangle .

The resolvent is singular whenever :math:`e^{i\omega}` is an eigenvalue of
:math:`T` — always at :math:`\omega = 0` — so the implementation projects out
the peripheral (unit-modulus) spectrum with its spectral projector :math:`Q`
and evaluates the equivalent, everywhere-finite form

.. math::

   P_c(\omega) = E[f(X_0)^2] - \langle \pi | \Omega (TQ)^{\#} \Omega | \mathbf{1} \rangle
     + 2\,\mathrm{Re}\,\langle \pi | \Omega \, (e^{i\omega} I - T(I-Q))^{-1} (I - Q)\, \Omega | \mathbf{1} \rangle .

.. note::

   **Delta peaks are excluded.** The DC peak :math:`2\pi E[f]^2\delta(\omega)`
   and, for processes with periodic components, peaks at the other roots of
   unity in the spectrum of :math:`T` are not part of the returned array. In
   particular a purely periodic process has :math:`P_c \equiv 0`, and
   :math:`P_c` is unchanged by centering :math:`f`. At :math:`\omega = 0` the
   returned value is the (finite) Green–Kubo limit of the continuous part.

A flat :math:`P_c` does not imply an i.i.d. process: Riechers & Crutchfield
:cite:`riechers2019fraudulent` construct arbitrarily structured "fraudulent
white noise" processes whose pairwise statistics vanish.

Mutual information function
===========================

:func:`mutual_information_function` returns :math:`I[X_0 : X_\tau]` in bits
for :math:`\tau = 0, \ldots, L` (entry 0 is :math:`H[X_0]`) from the exact lagged
joint law

.. math::

   P(X_0 = x, X_\tau = y) = \langle \pi | T^{(x)} \, T^{\tau-1} \, T^{(y)} | \mathbf{1} \rangle .

Unlike :math:`\gamma`, it depends only on which symbols are distinct, not on
their numeric values, and it decays at roughly twice the rate set by the
subdominant eigenvalue of :math:`T` (for the golden mean process,
:math:`I[X_0 : X_{\tau+1}] / I[X_0 : X_\tau] \to \lambda_2^2`).

Example
=======

.. code-block:: python

   import numpy as np
   from sofic.examples import golden_mean
   from sofic.generators.correlations import (
       autocorrelation,
       mutual_information_function,
       power_spectrum,
   )

   process = golden_mean(0.5)
   autocorrelation(process, 5, centered=True)   # Var * (p - 1)**tau
   power_spectrum(process, np.linspace(0, np.pi, 64))
   mutual_information_function(process, 10)
