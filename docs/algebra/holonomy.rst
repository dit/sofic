**********************
Holonomy Decomposition
**********************

The holonomy method of Zeiger :cite:`Zeiger1967` and Eilenberg
:cite:`Eilenberg1976` builds a cascade product that emulates a
transformation semigroup. Each level of the cascade is a permutation group
(a *holonomy group*) together with constant maps (resets). The implementation
follows the constructive proof of Egri-Nagy & Nehaniv
:cite:`EgriNagyNehaniv2015`:

1. The **extended image set** contains the images ``Q · s`` of the full state
   set, plus all singletons. A set ``P`` approximates any state ``x ∈ P``.
2. Sets that are images of each other are **equivalent**, and the classes are
   the strongly connected components of ``S`` acting on image sets.
   **Subduction** (``P ⊆ R · s`` for some ``s``) orders the classes. The
   **height** of a set is the length of the longest strict subduction chain of
   non-singletons ending at it, and the cascade has one level per height,
   numbered by depth from the top.
3. The **tiles** of a set are its maximal proper subsets in the image set. A
   class representative's **holonomy group** is the permutation group its
   setwise stabilizer induces on its tiles. It is generated by round trips
   through the class, so it is computed from the generators alone, even when
   ``S`` is too large to enumerate.

A state is lifted to a maximal chain of tiles from ``Q`` down to the state's
singleton. Each tile in the chain, recorded relative to its parent's class
representative, becomes one cascade coordinate. An input acts on a chain
level by level, from the top. Each level either applies a holonomy
permutation or resets, and the choice depends only on the coordinates above
it.

.. ipython::

   In [1]: from sofic.algebra import TransformationSemigroup, holonomy_decomposition

   In [2]: sg = TransformationSemigroup({"s1": (1, 0, 2), "s2": (0, 1, 1)})

   In [3]: hd = holonomy_decomposition(sg)

   @doctest
   In [4]: [level.order for level in hd.levels]
   Out[4]: [1, 2]

   In [5]: cascade = hd.to_cascade()

   @doctest
   In [6]: cascade.emulates(sg)
   Out[6]: True

This is Example 7.1 of :cite:`EgriNagyNehaniv2015`. ``{0, 1}`` is swapped by
``s1``, which gives a cyclic group of order two at depth 2. The top level
only records whether the state lies in ``{0, 1}`` or ``{2}``.
:meth:`HolonomyDecomposition.describe` summarizes the levels.
:meth:`~sofic.algebra.cascade.CascadeProduct.emulates` checks that decoding
commutes with every generator, so each decomposition verifies itself.
:meth:`~sofic.algebra.cascade.CascadeProduct.as_dfa` returns the cascade as
an ordinary :class:`~sofic.automata.dfa.DFA` on coordinate tuples.
