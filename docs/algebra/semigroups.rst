*************************
Transformation Semigroups
*************************

A :class:`TransformationSemigroup` is generated by labeled total maps of a
finite set, acting on the right so that a word is read left to right
:cite:`Eilenberg1976`. Its elements are enumerated lazily by breadth-first
closure, and each one keeps a shortest generating word. A ``max_size`` cap
raises :class:`~sofic.exceptions.SemigroupTooLargeError`, because ``n``
states can generate up to ``n**n`` maps. Partial maps, such as the undefined
moves of a unifilar presentation, are completed with an absorbing ``SINK``
state.

.. ipython::

   In [1]: from sofic.algebra import TransformationSemigroup

   In [2]: t3 = TransformationSemigroup({"t": (1, 0, 2), "c": (1, 2, 0), "e": (0, 0, 2)})

   @doctest
   In [3]: len(t3), t3.is_aperiodic()
   Out[3]: (27, False)

   @doctest
   In [4]: t3.word(t3.evaluate("ec"))
   Out[4]: ('e', 'c')

These three generators give the full transformation monoid ``T_3``. Any sofic
model with symbol-labeled edges converts with
:func:`~sofic.algebra.adapters.transformation_semigroup`, or with the
``transition_semigroup()`` method on automata, ε-machines, and sofic shifts:

.. ipython::

   In [1]: from sofic.examples import even_process

   In [2]: sg = even_process().transition_semigroup()

   @doctest
   In [3]: sg.states, len(sg)
   Out[3]: (('A', 'B', SINK), 7)

Green's relations
=================

:func:`~sofic.algebra.green.green_structure` computes the R-, L-, H-, and
D-classes (D = J for finite semigroups) as strongly connected components of
the Cayley graphs :cite:`Green1951` :cite:`Pin1986`. Each D-class is laid out
as an egg box of H-classes, and the H-class of an idempotent is a maximal
subgroup, returned as a sympy permutation group on the idempotent's image.

.. ipython::

   In [1]: green = t3.green()

   @doctest
   In [2]: [d.size for d in green.d_classes]
   Out[2]: [6, 18, 3]

   @doctest
   In [3]: [int(group.order()) for _, group in green.maximal_subgroups()]
   Out[3]: [6, 2, 1]

Every finite semigroup has a unique minimal ideal: the J-class below all
others, which for transformations consists of the elements of least rank
:cite:`Howie1995`. ``S`` contains a constant map, so the automaton is
synchronizing, exactly when that rank is one.
:meth:`~sofic.algebra.transformation.TransformationSemigroup.is_synchronizing`
decides this from the generators by merging pairs of states
:cite:`Volkov2008`. :meth:`~sofic.algebra.green.GreenStructure.schutzenberger_group`
gives the Schützenberger group of any H-class, regular or not.

.. ipython::

   @doctest
   In [1]: green.minimal_rank(), t3.is_synchronizing()
   Out[1]: (1, True)

Syntactic monoids and star-free languages
=========================================

The syntactic monoid of a regular language is the transition monoid of its
minimal complete DFA :cite:`Pin1986`. Because it is the smallest monoid that
recognizes the language, its properties belong to the language rather than to
any particular automaton. A language is star-free iff its syntactic monoid is
aperiodic :cite:`Schutzenberger1965`, which is also iff it is first-order
definable :cite:`McNaughtonPapert1971`.

.. ipython::

   In [1]: from sofic.algebra import is_star_free, syntactic_monoid

   @doctest
   In [2]: is_star_free("(ab)*", alphabet="ab"), is_star_free("(aa)*", alphabet="a")
   Out[2]: (True, False)

:func:`~sofic.algebra.syntactic.factor_monoid` makes every state initial and
accepting, so it describes the words labeling paths in a machine. For a shift
presentation that is the factor language ``B(X)``;
:func:`~sofic.shifts.invariants.factor_syntactic_monoid` and
:func:`~sofic.shifts.invariants.factor_krohn_rhodes_complexity` package it as
presentation-independent shift invariants. The Wheeler constructions use the
same test to say whether a failed search was doomed from the start, since
Wheeler languages are star-free :cite:`Alanko2021`.

Language varieties
==================

Eilenberg's variety theorem matches classes of regular languages with
classes of finite monoids, so a language's class can be read off identities
in its syntactic monoid or semigroup :cite:`Eilenberg1976` :cite:`Pin1986`.
:mod:`sofic.algebra.varieties` decides the classic ones:

* Piecewise testable (scattered subwords up to some length) iff the syntactic
  monoid is J-trivial :cite:`Simon1975`.
* Locally testable (prefixes, suffixes, and factors up to some length) iff
  the syntactic semigroup is locally idempotent and commutative
  :cite:`BrzozowskiSimon1973` :cite:`McNaughton1974`.
* Definite or reverse definite (a bounded suffix or prefix decides
  membership) iff ``se = e`` or ``es = e`` for every idempotent ``e``
  :cite:`Pin1986`.
* Group languages and commutative languages, plus R-, L-, and J-triviality.

.. ipython::

   In [1]: from sofic.algebra import is_locally_testable, is_piecewise_testable, is_definite

   @doctest
   In [2]: is_locally_testable("(ab)*", alphabet="ab"), is_piecewise_testable("(ab)*", alphabet="ab")
   Out[2]: (True, False)

   @doctest
   In [3]: is_definite("(a|b)*a", alphabet="ab")
   Out[3]: True

Shifts of finite type have locally testable factor languages, which
``is_locally_testable(factor_monoid(shift, monoid=False))`` confirms. The even
shift's language is not locally testable.
