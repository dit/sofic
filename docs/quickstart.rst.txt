
.. _quickstart:

Quickstart
----------

The basic workflow is the same for every model: build (or load) a model,
call ``validate()``, then compute properties or convert to another
presentation. States can be any hashable object, and every model exposes
``states()``, ``transitions()``, ``draw()``, and ``to_yaml()``.

Stochastic generators
~~~~~~~~~~~~~~~~~~~~~~~

Build the golden mean process (forbid-``11`` convention) as an ε-machine and
read off computational-mechanics quantities :cite:`Crutchfield1994,Ellison2009`:

.. ipython::

   In [1]: import pensive; from pensive.examples import golden_mean

   In [2]: eps = golden_mean(0.5)

   @doctest float
   In [3]: eps.entropy_rate()
   Out[3]: 0.6666666666666665

   @doctest float
   In [4]: eps.statistical_complexity()
   Out[4]: 0.9182958340544896

   @doctest
   In [5]: eps.markov_order()
   Out[5]: 1

   @doctest
   In [6]: eps.cryptic_order()
   Out[6]: 1

Finite automata
~~~~~~~~~~~~~~~

Recognize the language of strings with an even number of ``b``\ s, then
minimize and extract a regular expression:

.. ipython::

   In [1]: from pensive import DFA

   In [2]: dfa = DFA(input_alphabet=frozenset({"a", "b"}), initial_states=frozenset({"even"}), accepting_states=frozenset({"even"}))

   In [3]: dfa.graph.add_state("even"); dfa.graph.add_state("odd")

   In [4]: dfa.add_transition("even", "even", "a"); dfa.add_transition("even", "odd", "b");

   In [5]: dfa.add_transition("odd", "odd", "a"); dfa.add_transition("odd", "even", "b");

   In [6]: dfa.validate()

   @doctest
   In [7]: dfa.recognizes("abba"), dfa.recognizes("abbb")
   Out[7]: (True, False)

Symbolic shifts
~~~~~~~~~~~~~~~

Present the golden-mean shift as a topological Markov chain and compute its
topological entropy (the log of the golden ratio) :cite:`LindMarcus1995`:

.. ipython::

   In [1]: import numpy as np; from pensive import TopologicalMarkovChain

   In [2]: tmc = TopologicalMarkovChain.from_adjacency(np.array([[1, 1], [1, 0]], dtype=float), symbol_alphabet=frozenset({0, 1}))

   In [3]: tmc.validate()

   @doctest float
   In [4]: tmc.topological_entropy()
   Out[4]: 0.4812118250596035

The Parry measure turns the shift into the maximum-entropy ``MealyHMM`` on it
(``tmc.parry_measure()``), the measure that attains this topological entropy.

Bidirectional ε-machine
~~~~~~~~~~~~~~~~~~~~~~~

A bidirectional presentation pairs forward and reverse causal states, exposing
the excess entropy and crypticity:

.. ipython::

   In [1]: from pensive.examples import golden_mean_bidirectional

   In [2]: bidir = golden_mean_bidirectional(0.5)

   @doctest float
   In [3]: bidir.statistical_complexity()
   Out[3]: 1.584962500721156

   @doctest float
   In [4]: bidir.excess_entropy()
   Out[4]: 0.25162916738782304

   @doctest float
   In [5]: bidir.crypticity()
   Out[5]: 1.333333333333333

Information anatomy
~~~~~~~~~~~~~~~~~~~

Bound and ephemeral information rates from a bidirectional ε-machine
:cite:`James2013`:

.. ipython::

   In [1]: from pensive.examples import tent_map_misiurewicz_bidirectional; bidir = tent_map_misiurewicz_bidirectional()

   @doctest float
   In [2]: bidir.entropy_rate()
   Out[2]: 0.8231724556945506

   @doctest float
   In [3]: bidir.bound_information()
   Out[3]: 0.174914618901008

   @doctest float
   In [4]: bidir.ephemeral_information()
   Out[4]: 0.648257836793596

Edge machines
~~~~~~~~~~~~~

Convert a non-unifilar HMM into a Mealy generator whose states index labeled
transitions:

.. ipython::

   In [1]: from pensive.examples import tent_map_misiurewicz_hmm; edge = tent_map_misiurewicz_hmm().to_edge_machine()

   @doctest
   In [2]: len(list(edge.states()))
   Out[2]: 7

Inference from data
~~~~~~~~~~~~~~~~~~~~

Reconstruct an ε-machine from a sampled sequence with Causal-State Splitting
Reconstruction :cite:`Shalizi2004`, or compare candidate Markov orders with
exact Bayesian evidences :cite:`Strelioff2014`. See :doc:`inference/inference`.

Converting between presentations
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The presentations are linked by a web of conversions: HMMs minimize to
ε-machines (:meth:`~pensive.generators.epsilon_machine.EpsilonMachine.from_hmm`),
probabilistic models drop their weights to become automata or shifts
(:meth:`~pensive.generators.base.HiddenMarkovModel.to_sofic_shift`,
:meth:`~pensive.generators.base.HiddenMarkovModel.to_support_dfa`), NFAs
determinize to DFAs (:meth:`~pensive.automata.nfa.NFA.determinize`), and shifts
yield their maximum-entropy measure
(:meth:`~pensive.shifts.tmc.TopologicalMarkovChain.parry_measure`). Every model
round-trips through YAML via ``to_yaml`` / ``from_yaml``.
